# 🚀 راهنمای نصب و راه‌اندازی (Deploy) پروژه GitiArts

این مستند برای استقرار پروژه روی سرور (VPS) نوشته شده است.

## 📌 ۱. پیش‌نیازهای سرور
- **سیستم‌عامل:** لینوکس (Ubuntu 22.04 یا بالاتر توصیه می‌شود)
- **وب‌سرور:** Apache یا Nginx
- **زبان:** PHP نسخه ۸.۰ یا بالاتر
- **پایگاه داده:** SQLite (پیش‌فرض) یا PostgreSQL (در صورت استفاده از تملتی)
- **افزونه‌های PHP:** `pdo`, `pdo_sqlite`, `pdo_pgsql`, `mbstring`, `json`, `curl`

## 📤 ۲. آپلود فایل‌ها
1. فایل‌های پروژه را با استفاده از FTP یا SFTP به سرور منتقل کنید.
2. مسیر پیشنهادی برای وب‌سرور: `/var/www/html/menu`
3. **نکته امنیتی:** حتماً پوشه `.git` و فایل‌های `cleanup-repo.php` و `fix-*.php` را در سرور نداشته باشید.

## 🔐 ۳. تنظیم دسترسی‌ها (Permissions)
برای اینکه سیستم بتواند فایل‌های JSON و تملت‌ها را بنویسد، باید دسترسی پوشه‌های داده را تنظیم کنید:
```bash
# دادن دسترسی نوشتن به پوشه داده‌ها و تملت‌ها
sudo chmod -R 775 data/
sudo chmod -R 775 "menu(1)/menu/tenants/"
